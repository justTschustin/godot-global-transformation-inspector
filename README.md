# Godot Global Transformation Inspector

This is a simple Godot addon adding global transformation information to the inspector.
It displays a node's global position and global rotation at the bottom of the inspector.

## Installation
Either:
- download the zip file from [Releases](https://github.com/justTschustin/godot-global-transformation-inspector/releases)
  - unzip in your Godot project root

Or:
- clone the project to `<my-project>/addons/`
